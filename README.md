
# Credit Scoring Model Using Machine Learning

## 📌 Project Overview

This project predicts the credit score/category of customers using Machine Learning techniques. The model analyzes customer financial and personal information to classify their creditworthiness.

## 🎯 Objective

The main objective is to build a Machine Learning model that can predict credit scores and help understand a customer's credit risk based on available data.

## 🛠️ Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## 🤖 Machine Learning Algorithms

* Logistic Regression
* Support Vector Machine (SVM)
* Random Forest Classifier

## 🔄 Project Workflow

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Selection
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Prediction

## 📊 Evaluation Metrics

The models are evaluated using:

* Accuracy
* Confusion Matrix
* Classification Report

## ▶️ How to Run

1. Open the `credit_scoring_model.ipynb` file in Google Colab.
2. Upload the required dataset.
3. Install the libraries from `requirements.txt`.
4. Run the notebook cells sequentially.

## 📁 Project Files

* `credit_scoring_model.ipynb` — Main Machine Learning notebook
* `requirements.txt` — Required Python libraries
* `README.md` — Project documentation
